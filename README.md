# Simulador Interactivo Unicauca

Simulador visual e interactivo de Estadística Inferencial para la Universidad del Cauca.

## ¿Qué incluye?

- Calculadora del Teorema Central del Límite (TCL).
- Cálculo de Error de muestra y Error Estándar.
- Gráficas tipo campana normal.
- Comparación visual de cómo cambia el Error Estándar cuando aumenta `n`.
- Calculadora de Intervalos de Confianza.
- Selección automática entre:
  - Distribución Z.
  - Distribución t de Student.
  - Modelo Z para proporciones.
- Casos precargados del documento de trabajo.
- Recomendaciones gerenciales automáticas.

## Cómo abrirlo localmente

Descarga este repositorio y abre el archivo:

```text
index.html
```

con doble clic en Chrome, Edge o Firefox.

No necesita instalar Python, numpy, matplotlib, scipy ni pandas.

## Cómo publicarlo con GitHub Pages

1. Sube todos los archivos de esta carpeta a un repositorio de GitHub.
2. En GitHub, entra a **Settings**.
3. Busca **Pages**.
4. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guarda los cambios.
6. GitHub generará un enlace público para abrir el simulador.
