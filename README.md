# Actividad Estadística - Simulador Unicauca

Este repositorio contiene la versión web estática del simulador de Estadística Inferencial.

## Enlace principal

GitHub Pages abre automáticamente:

```text
index.html
```

## Qué permite hacer

- Calcular escenarios del Teorema Central del Límite.
- Ingresar valores propios de μ, σ, n y límites.
- Calcular Error de muestra y Error Estándar.
- Calcular intervalos de confianza para medias y proporciones.
- Elegir automáticamente entre Z, t de Student o modelo de proporciones.
- Ver ecuaciones, procedimientos, recomendaciones y gráficas.
- Cargar los casos del PDF del trabajo.

## Importante

Esta versión funciona directamente en GitHub Pages porque está hecha en HTML, CSS y JavaScript.

GitHub Pages no ejecuta Python. Si se sube solo la versión Python, la página mostrará el README o archivos del repositorio, pero no correrá `app.py`.

## Cómo publicarlo

1. Sube estos archivos al repositorio.
2. Asegúrate de que `index.html` quede en la raíz del repositorio.
3. Ve a Settings > Pages.
4. Selecciona:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Guarda.
6. Abre el enlace de GitHub Pages.

## Uso

Abre la página, ingresa los datos y presiona calcular.
