4. Guía rápida para sustentación oral

¿Cuándo uso Z?

Se usa Z cuando la desviación estándar poblacional σ es conocida. También se usa como aproximación cuando la muestra es grande.

¿Cuándo uso t?

Se usa t de Student cuando σ es desconocida, usamos s muestral y la muestra es pequeña. La t tiene colas más anchas para reflejar mayor incertidumbre.

¿Cuándo uso proporciones?

Se usa cuando el parámetro es una proporción poblacional p. El estimador es p̂ = x/n.

¿Qué significa SE?

El Error Estándar mide cuánto varían los promedios muestrales. Si n aumenta, SE disminuye, por eso las estimaciones se vuelven más precisas.
