# Guía de sustentación

## Error de muestra

```text
error = x̄ - μ
```

Es la diferencia observada entre una media muestral específica y la media poblacional.

## Error Estándar

```text
SE = σ / √n
```

Mide la variabilidad esperada de las medias muestrales.

## TCL

Para medias:

```text
Z = (x̄ - μ) / (σ / √n)
```

Para sumas:

```text
E(S) = nμ
SD(S) = σ√n
Z = (S - nμ) / (σ√n)
```

## Intervalos de Confianza

```text
estimador ± valor crítico × SE
```

- Z: cuando σ es conocida o la muestra es grande.
- t: cuando σ es desconocida y n es pequeño.
- Proporciones: cuando el parámetro es p y se estima con p̂=x/n.
